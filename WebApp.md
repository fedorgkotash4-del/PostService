# Вебзастосунок Облік поштових відправлень

Власна реалізація на ASP.NET Core Razor Pages у проєкті `PostService.WebApp`.
Використано структуру та кольори власних макетів `Design/PR44/web` і адаптивні
картки з `Design/PR44/mobile`. Демонстраційний репозиторій викладача не використовувався.

## Запуск

Windows або інша система з .NET SDK 10 для API та вебклієнта.
У Visual Studio відкрийте `PostServiceSolution/PostService.slnx` і виберіть
«PostService — сервер і вебклієнт». У VS Code відкрийте `PostService.code-workspace`
та запустіть однойменний профіль. Windows Forms залишається окремим клієнтом.

Для запуску з двох терміналів із каталогу `PostServiceSolution`:

```powershell
dotnet run --project PostService
dotnet run --project PostService.WebApp
```

Вебкабінет: http://localhost:5080. API: http://localhost:5036.
Адреса API задається в `PostService.WebApp/appsettings.json` або через
змінну `PostServiceApi__BaseUrl`, наприклад `http://localhost:5036/`.
Клієнт викликає наявні REST-ендпойнти через HttpClient; прямого доступу до бази не має.
Зміни видимі в обох клієнтах, якщо вони використовують один запущений API.

## Сторінки та дії

- `/` — головна з переходами до списку, створення та інформації про програму.
- `/About` — опис можливостей і збереження даних.
- `/Postings` — список, пошук, оновлення та дії з окремим записом.
- `/Postings/Edit` — створення; `/Postings/Edit/{id}` — редагування тією самою формою.
- `/Postings/Details/{id}` — перегляд параметрів без редагування.
- `/Postings/Delete/{id}` — підтвердження; тільки POST виконує видалення.

## Правила

Обов’язкові відправник з адресою, одержувач з адресою та вміст. Вага й габарити
додатні; цінність необов’язкова та невід’ємна. Опис необов’язковий. Ціну створення
обчислює сервер; у редагуванні доступна невід’ємна ціна. Числа приймають кому й крапку.
Перевірка виконується на вебсервері та працює без JavaScript. Після помилки поля
залишаються заповненими; після успіху виконується перехід до актуального списку.
Скасування не надсилає змін. Повідомлення про відсутній запис чи недоступний API
показуються на сторінці. Форми мають стандартний захист від підроблених POST-запитів,
а введений текст кодується Razor під час відображення.

## Перевірка

Перевірено у справжньому Chrome: навігацію, створення, розрахунок ціни сервером,
редагування, скасування, незмінність дати створення, порожні необов’язкові поля,
валідацію, пошук, деталі, підтвердження/скасування/виконання видалення та відсутній запис.
Перевірено адаптивність на ширині 390 пікселів, захист POST і відображення HTML як тексту.
Тестові дані та звіт не включаються до Git. Готова локальна збірка — `Deliverables/WebApp`.
